# 统一身份登录与协作空间

## 目标与已核实契约

接入现有 KX 身份系统；用户拥有私人记忆和编剧角色，也能加入共享空间共同上传作品、讨论、提炼和发布同一角色。生成仍由外部 Agent 执行。

KX 源码提供 `/auth/user/access_token`、`/auth/user/user_info`、`/auth/dt/apps`、`/auth/dt/login`、`/auth/dt/exchange`。响应使用 KxEd 传输封装与 `{code,result,msg}`，不能假设是标准 OAuth 服务。实际支持的登录类型取决于 KX 实现，不能仅凭 LoginType 枚举宣称全部可用。

直接支持 KX 账号密码、钉钉应用选择和一次性票据回调；另外支持配置 OAuth2 授权码服务（S256 PKCE、固定回调地址、服务端令牌交换及用户信息校验）。配置授权地址必须同时指定令牌地址与用户信息地址，不能信任回调中的用户 ID。

## 隔离与权限

每个空间独立 SQLite、向量索引、认知引擎、事件通道和编剧数据。认证 SQLite 仅管理外部身份、空间成员、会话、Agent 凭据、邀请和审计。用户身份使用服务端验证的 `(issuer, subject)`；不信任浏览器提供的用户 ID、目录或模型返回的权限。

首次登录创建私人空间。共享空间由用户创建，通过一次性限时邀请加入；权限为 owner、editor、viewer。owner 管理成员、发布/回滚/删除角色；editor 上传资料、聊天、提交提炼候选及撰写草稿；viewer 查看与检索。私人空间不可邀请成员。共享空间内的记忆、作品、角色、项目对该空间成员共享；需要更小的分享边界时创建独立空间。

所有 HTTP API、下载、WebSocket、MCP 会话先校验身份和空间成员资格，再选择空间运行时。MCP 会话绑定凭据、用户和空间；每次调用重新校验撤销与成员权限。身份模式关闭旧的全局服务令牌入口，禁止无身份 stdio；Agent 使用网页创建的限时空间令牌。系统文件访问、源连接器、全局验证器、文件路径恢复等功能不开放给租户。

## 会话与回调

HttpOnly、SameSite=Lax cookie；HTTPS 使用 Secure。回调使用随机 state 和独立浏览器绑定 cookie，5 分钟过期并一次性消费。只使用配置中的回调 origin，不接受客户端任意返回地址。密码不落盘；上游 token 加密保存，本地会话和 Agent token 仅存摘要；上游 token 的有效期限制本地会话寿命，并定期重新检查用户身份/禁用状态。退出撤销当前浏览器会话，Agent token 可单独撤销。

POST/DELETE 等浏览器请求强制匹配配置 origin；CORS 不替代 CSRF 校验。带身份的响应禁止缓存，回调禁止 Referer 泄漏。WebSocket 定期复核授权并在退出、撤权或空间切换后关闭。权限默认拒绝，新增工具或敏感 API 必须显式加入允许规则。

## 本地数据与运行

登录功能通过私有 `auth.json` 显式启用，未配置时保持原本单用户离线模式。旧数据库不自动分配给首个登录者；仅当配置 `legacy_owner_subject` 明确绑定 KX 用户时，该用户获得旧资料空间。原库不搬移、不清空。备份必须覆盖认证数据库、加密密钥、所有空间数据库和旧库，按 SQLite 一致性快照执行。

桌面复用本机服务，网页登录在当前 WebView 内完成；后端响应钉钉跳转。如果外部平台限制嵌入登录，可使用同一浏览器打开本地地址。服务器部署以 HTTPS 反向代理为入口，服务默认仍监听回环。

## 自审与验收

- 验证两个用户的列表、精确 ID、搜索、图谱、文件、任务、草稿与 MCP 会话交叉访问均失败。
- 验证同一共享角色可由两个 editor 分别上传和提交证据；viewer 写入、editor 发布/删角色失败。
- 验证邀请过期/重放、回调 state 错误/重放、跨站请求、已撤销 token 与 WebSocket 撤权。
- 验证本地单用户模式兼容、旧数据不被自动认领、无模型构建与完整模型构建。
- 真实站点只做公开接口/跳转契约检查；真实账号登录需要用户操作，不能用模拟身份宣称真实登录已通过。

## 实现自审记录

已完成 KX 传输接入、账号密码与钉钉票据登录、可配置 OAuth2/PKCE、认证数据库、独立空间运行时、成员邀请与权限、个人 MCP 凭据、网页登录与账户页面、桌面登录导航，以及完整空间备份。

自审修正：

- 本机 Origin 检查只在单用户模式保留；身份模式统一检查配置 origin 与会话，不因请求来自本机跳过用户认证。
- 只共享已验证的模型运行实例；记忆、向量、查询缓存、认知状态和事件通道独立。非空空间禁止隐式迁移模型。
- 后台认知任务由空间持有并可取消。HTTP、WebSocket 与 MCP 会话保留运行时生命周期；先清理过期 MCP 会话，再释放空闲空间。
- 公开健康检查不泄漏记忆数量。全局文件、连接器、验证器接口不进入租户允许列表。
- 切换空间或退出后通知其他标签页刷新；浏览器历史恢复时重新验证身份。
- 备份去除会话、Agent 凭据和待使用邀请，避免恢复旧授权。

验证：后端库 660 项测试通过；身份专项最终 14 项通过，覆盖 PKCE、空间隔离、成员撤权、WebSocket、无效配置拒绝开放旧路由与后台任务释放；模型隔离 2 项通过；前端 842 项通过；Svelte 检查 0 错误/0 警告；严格 Clippy 与 Tauri 生产构建通过。真实浏览器使用三个标注为模拟的用户完成登录、共同上传、MCP 调用与撤权。真实 KX 的公开应用列表和本地生产登录页已联通，真实用户扫码或密码登录由账号持有人完成。

边界：共享空间内全部资料对成员可见；个人 Agent 凭据最长 8 小时，不提供长期离线身份授权。未实现完整 OIDC 发现与 ID Token 验证、跨空间混合检索、空间所有权转移或面向租户的服务器文件管理。
