# 编剧工作台设计自评

评审对象：[WRITER-STUDIO.md](WRITER-STUDIO.md)。评审方式：对照现有源码、用户选择、Tauri 官方文档和实际部署结果，由本任务自行评审。用户已授权自评后实现；不把本记录表述为用户逐项签字。

## 发现的问题与已经纳入的决定

| 编号 | 问题 | 设计修订 |
|---|---|---|
| R1 | “对话系统”容易被误实现为服务端偷偷调用生成模型，与用户选择不符 | 提炼、对话、写作和审稿均走外部 Agent 持久化任务；没有 Agent 时明确等待 |
| R2 | 把角色提示词覆盖写回会破坏可复现性，且旧任务可能覆盖新偏好 | 不可变版本、base_version、候选/发布分离、项目固定版本、过期结果拒绝 |
| R3 | 一份作品摘要不等于可执行的编剧方法 | 规则必须含用途、适用条件、例外和具体来源证据；单独保留原始素材 |
| R4 | MCP schema 如果只提供“生成剧本”，Agent 无法知道该读什么、如何提交 | 显式七类工具，领取/续期/完成协议，来源分页及固定版本上下文 |
| R5 | 直接将现有前端放到 Tauri asset origin 会破坏相对 API 和 WebSocket | 桌面连接同源本地服务，复用现有路由；原生权限与网页权限分离 |
| R6 | Tauri 关闭窗口可能杀掉 Agent 正在使用的服务 | 接入现有服务不拥有其生命周期；关闭隐藏，明确退出只停止自己启动的侧车 |
| R7 | 当前 stdio EOF 路径不能直接作为守护服务 | 增加完整 `--daemon` 生命周期，避免使用缺少模型/维护的旁路启动 |
| R8 | 英文 MSDF 字体和 WebGPU 画布不保证显示中文 | 中文标签采用 DOM/Unicode 可用路径；逐页浏览器及实际 WebKit 验证 |
| R9 | 只把上传原件放磁盘会使现有数据库备份不完整 | 原件、解析结果、角色、任务、草稿统一进入 SQLite；明确传统导出的边界 |
| R10 | 删除作品后规则仍引用已删除片段，会制造伪证据 | 删除派生内容并让相关规则失效，审计只保留内容无关标识 |
| R11 | 只靠 scope 标签不足以防跨角色/项目串数据 | 每条领域操作验证实体归属，来源引用与项目版本在服务端校验 |
| R12 | 自动重试会重复发布版本或覆盖草稿 | 任务完成幂等、lease token、原子状态转换、预期修订号 |
| R13 | 上传和嵌入会抢占 16 GB Mac 的服务资源 | 文件/解压/解析限制、有界后台工作、单模型实例、Agent 分页阅读 |
| R14 | 中文“支持”若只翻译导航，用户仍遇到整页英文 | 将全路由正文、动态状态、错误、无障碍和图形标签列入完成标准 |
| R15 | 单独删除原件而保留历史任务回复，会遗漏派生正文；修改历史版本又破坏不可变契约 | 已参与提炼的作品禁止单独删除；明确告知关联关系，并提供删除整个角色的完整清除路径 |

## 评审结论

设计覆盖用户四项产品需求，生成责任与本地数据责任清晰；关键数据状态、外部 Agent 协议、Tauri 运行方式和验收证据已定义。**设计自评通过，进入实现。** 这不是实现通过的声明；各项完成仍须由实际代码、测试和运行证据证明。

## 实现复核结果

- 全 Rust 工作区（含 `qwen3-embeddings,metal`）：2,176 项通过、0 失败，32 项按原测试配置跳过。真实模型是否可用另外通过运行服务检查，不能用跳过的测试宣称已验证。
- 前端：842 项测试通过；Svelte / TypeScript 检查 0 错误、0 警告；生产构建成功。
- `tests/writer/test_http.py`：真实 daemon 在 stdin 关闭时持续服务；六种格式、伪证据拒绝、并发租约、完成幂等、项目版本固定、草稿审稿、重启及 SQLite 恢复通过。
- `tests/writer/browser.cjs`：真实浏览器操作与外部 MCP 客户端完成“上传 → 提炼 → 发布 → 对话 → 再发布 → 创作 → 审稿”，没有 JavaScript 错误。
- `tests/writer/audit-ui.cjs`：22 个已注册产品页面均为 `zh-CN`，无脚本或 HTTP 资源错误。模型 ID、工具名、追踪 ID 等协议/数据标识保留原样。
- Tauri：Apple Silicon `.app` 打包成功，原生 WKWebView 实际启动并截图。通过原生窗口 API 确认关闭后隐藏；MCP 保持可调用；明确退出只停止应用自己启动的侧车，外部服务保持运行。
- 上传限制：真实 HTTP 请求超过 50 MiB 时返回 413。
- 正式服务：数据库升级到 schema 37，保留原记忆、模型与认证配置；发现 22 个 MCP 工具，其中 7 个为编剧工具；数据库完整性检查通过。

## 验收中修正的问题

1. 迁移需要更新 schema 版本且可重复应用，否则重启会重复建表。
2. 图形层原有 ASCII 过滤会破坏中文；改为保留 Unicode 并补充本机字形。
3. 空库图谱应返回空集合，不能让新安装用户得到 404。
4. 原生关闭回调中的隐藏操作改为退出回调后交给事件循环处理，并以 `NSWindow.isVisible` 复核。
5. 首次模型下载不能无限延长 stdio / daemon 退出；运行时使用有界关闭。
6. 新增工具必须进入原有真实 stdio 覆盖门禁；原有工具目录仍维持 55 KB 上限，编剧工具单独限制 14 KB，并共享公共 schema 定义以减少重复。
7. 大文件分段不能插入原文不存在的字符；分段连接后须等于规范化原文。引用可按 segment_id 直接定位。
8. 普通对话可以只有回复，不强制制造规则；明确的规则变更仍使用候选版本。

以上结果验证实现与本地运行，不等同于“模型学会某位真实编剧”或商业效果评测。验收素材为明确标注的合成作品；真实作者素材尚待用户导入。
